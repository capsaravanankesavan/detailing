# SKU-Based Shortlisting — Reduce Evaluator Calls at 2K POS Promotion Scale

## Metadata

| Field | Value |
|-------|-------|
| Ticket | [CAP-196692](https://capillarytech.atlassian.net/browse/CAP-196692) |
| Description | New `ItemBasedShortlistingService` recursively extracts SKU-IN criteria from a promotion's Condition tree (all 10 Condition subtypes, incl. accumulation-safety reward-side extraction) and excludes promotions whose required SKU is absent from the cart, before the expensive downstream `PromotionCappingShortlistingService`.
